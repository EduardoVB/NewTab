NEWTABCTL REFERENCE

Introduction:
NewTab is a tab control for VB6. It is a drop-in replacement for the Microsoft SSTab control: an SSTab placed on a form can be replaced with a NewTab and the form keeps its tabs, captions, pictures and contained controls, and the code that uses the SSTab members keeps working. It was formerly called SSTabEx.

Beyond SSTab, it adds:
- Five styles (Style): the two of SSTab (tabbed dialog and property page), TabStrip, Flat and Windows (drawn with the Windows visual styles).
- Twelve tab orientations (TabOrientation), including tabs at the right or bottom end of a side, and side tabs with horizontal captions.
- Themes (Theme): named sets of appearance settings. 83 are built in, and custom themes can be saved to a file, to the registry or to the form.
- Two TDI modes (TDIMode), "Tabbed Document Interface": one where each tab is a copy of a set of controls, and one where each tab hosts a form, like a tabbed MDI.
- Close buttons (CloseButton), a new tab button (NewTabButton), and a scrolling tab strip with a tab list (TabsOverflow).
- Tab reordering by dragging (CanReorderTabs).
- Icons from icon fonts (IconCharHex), also in color (IconInColor), besides pictures.
- Hover highlighting with many options (HighlightMode), and animated effects.
- Full RightToLeft support, in every orientation and style.
- DPI awareness: sizes in pixels are scaled with the DPI, and tab pictures are scaled (ScalePicturesForDPI).
- Adding and removing tabs at run time (AddTab, RemoveTab), and helpers for the contained controls (ControlSetTab, FitToClientArea).

Working with contained controls.
Like with SSTab, each contained control belongs to one tab, and the controls of the tabs that are not selected are moved far to the left (LeftOffsetToHide) to hide them. So:
- At run time, don't read the Left of a contained control to know where it is: use ControlLeft, and ControlMove instead of its Move method.
- To put a control of the form into a tab by code, first set its Container to the NewTab and then call ControlSetTab:

Set Text1.Container = NewTab1
NewTab1.ControlSetTab Text1, 2

- A control created with Controls.Add goes in the same way. To handle its events, declare a WithEvents variable of its type:

Private WithEvents mButton As CommandButton

Private Sub Form_Load()
    Set mButton = Controls.Add("VB.CommandButton", "cmdNew")
    Set mButton.Container = NewTab1
    NewTab1.ControlSetTab mButton, 1
    mButton.Move NewTab1.ClientLeft + 120, NewTab1.ClientTop + 120
    mButton.Visible = True
End Sub

- The space inside the body is given by ClientLeft, ClientTop, ClientWidth and ClientHeight, in twips. FitToClientArea makes a control fill that space and keeps it fitted.

Differences with SSTab that matter when porting code
- Removing tabs that still hold controls raises error 1390, not 380.
- At run time all the tabs can be removed or hidden. Then Tab is -1.
- RemoveTab and AddTab exist; with SSTab the only way was changing Tabs.
- TabHeight is calculated automatically while AutoTabHeight is True, the default for a new control. Setting TabHeight turns it off.
- The default Style of a new control is Windows (ntStyleWindows), not tabbed dialog.
- Many properties have an Auto value that follows Style. A theme sets fixed values instead.
- Errors raised for invalid arguments follow VB's rules: error 5 from methods, error 381 for an invalid tab index in a property, error 380 for an invalid property value. The control's own errors are numbered from 1380.

*NewTab control*
- Tab control for VB6, compatible with SSTab.

The control shows a strip of tabs and a body. Each tab has its own set of contained controls, and only the controls of the selected tab are visible.

The current tab is set or read with the Tab property. Changing it raises the BeforeClick, Click and TabChange events, in that order.
The properties that start with Tab and take an index, like TabCaption or TabVisible, work on one tab. Their index parameter, nTab, can be the tab index (zero based), its TabKey, or its TabCaption.
The properties without an index that refer to one tab, like Caption or Picture, work on the selected tab, as they do in SSTab.

Properties: 

AutoRelocateControls property:
	Type: NTAutoRelocateControlsConstants
	Returns or sets a value that determines whether the contained controls are moved automatically when the body changes its position.
	
	The body moves when the tab strip changes: another TabOrientation, more or fewer rows of tabs, a different TabHeight, Style or font. The contained controls are moved by the same amount, so they keep their place relative to the body.
	
	Values:
	ntRelocateAlways (default): the controls are moved whenever the body moves.
	ntRelocateOnTabOrientationChange: the controls are moved only when TabOrientation changes.
	ntRelocateNever: the controls are never moved. Choose this value if your code places them, for example in the Resize event.
	
	Note: after changing by code something that moves the body, place new controls reading ClientLeft and ClientTop, which applies the pending change first. A control moved to fixed numbers before that is moved again when the control redraws.


AutoTabHeight property:
	Type: Boolean
	Returns or sets a value that determines whether the height of the tabs (TabHeight) is calculated automatically.
	
	When True, the height is calculated from the Font, TabPaddingHeight, the icons and pictures of the tabs, the close button and the other glyphs that the tabs can show. It is recalculated whenever any of these change.
	Setting TabHeight sets AutoTabHeight to False.
	
	The height is calculated for captions of one line. With WordWrap set to True, a caption that doesn't fit in the length of the tab is split in two lines but the tab doesn't grow, so the second line can be cut. That happens only when the length of the tab doesn't come from its caption: with ntTWEqualWidth, TabsPerRow, a fixed width, or the side orientations. In those cases set WordWrap to False (the caption gets an ellipsis) or set TabHeight by hand.
	
	The default is True for new controls. Forms saved with earlier versions of the control, and forms converted from SSTab, keep False.


BackColor property:
	Type: Long
	Returns or sets the background color of the control: the color of the area that is not covered by the tabs or the body, like the space at the end of the tab strip.
	While it is not set, it follows the background color of the container.
	
	It is not the color of the tabs: the inactive tabs use BackColorTabs, and the selected tab and the body use BackColorSelectedTab.
	With BackStyle set to transparent, this area is not painted.


BackColorSelectedTab property:
	Type: Long
	Returns or sets the color of the selected tab and of the body (the area where the contained controls are).
	
	While it is not set, it is calculated from BackColorTabs: the same color, or a variant of it in the Flat style.
	If ChangeControlsBackColor is True, the contained controls that have this color as their BackColor follow it when it changes.
	While the tabs are drawn with the Windows visual styles, the body and the selected tab are painted by Windows and this color is not used for them.
	
	A tab can have a color of its own with TabCustomColor.


BackColorTabs property:
	Type: Long
	Returns or sets the background color of the inactive tabs. The selected tab uses BackColorSelectedTab, which follows this color while it is not set.
	While the tabs are drawn with the Windows visual styles, the tabs are painted by Windows and this color is not used for them.
	
	A tab can have a color of its own with TabCustomColor.


BackStyle property:
	Type: NTBackStyleConstants
	Returns or sets which parts of the control are left transparent, so that the container shows through.
	
	Values:
	ntOpaque (default): everything is painted.
	ntTransparentBackOnly: only the area painted with BackColor is transparent. The tabs and the body are painted.
	ntTransparent: the area of BackColor and also the body and the selected tab are transparent. The inactive tabs are painted.
	
	The transparent parts don't receive mouse clicks: they go to what is behind.
	With ntTransparent the tabs can't be drawn with the Windows visual styles, and the Windows style is drawn like the TabStrip style.
	At run time, when no tab is visible and there is no new tab button, the whole control is transparent.


CanReorderTabs property:
	Type: Boolean
	Returns or sets a value that determines whether the user can change the order of the tabs by dragging them with the mouse.
	
	It works in all the orientations, with one or several rows of tabs, and with RightToLeft.
	While a tab is dragged the others open a gap where it will fall, and the order changes when the mouse button is released. Before that the BeforeTabReorder event is raised, where the move can be canceled or its destination changed, and after it the TabReordered event.
	TabMovable keeps a tab in its place. The new tab button and the tab 0 of the TDI modes never move.
	
	When the order changes, the tab indexes change. To find a tab after the user moved it, use its TabKey, TabData or TabTag, or its original index with FindTab. GetTabsOrder and SetTabsOrder save and restore the order, and need this property to be True.


Caption property:
	Type: String
	Returns or sets the caption of the selected tab. To read or set the caption of any tab, use TabCaption.
	A caption can have an access key: the letter after a "&" is underlined, and pressing ALT and that letter selects the tab. "&&" shows a "&".


CaptionAlignment property:
	Type: NTAlignmentConstants
	Returns or sets the alignment of the captions inside the tabs: ntAlignmentCenter (default), ntAlignmentLeft or ntAlignmentRight.
	It is noticed when the tab is wider than its caption.


CausesValidation property:
	Type: Boolean
	Returns or sets whether the Validate event of the control that is losing the focus is raised when the NewTab gets it.
	On a form, this is the property that VB adds to every control. The control also exposes it so that it can be reached from code that uses the control through a variable typed As NewTab.


ChangeControlsBackColor property:
	Type: Boolean
	Returns or sets a value that determines whether the BackColor of the contained controls is changed to the background color of the selected tab. The default is True.
	
	The controls that are changed are the ones whose BackColor is the color the tab control gave them before (at first, the same color as the body). A control with a different BackColor is left as it is.
	So when BackColorSelectedTab changes, a theme is applied, or a tab with a color of its own (TabCustomColor) is selected, those controls follow the color of the body.
	The ChangeControlBackColor event allows to exclude some controls.
	
	When the body is drawn with the Windows visual styles, it is lighter than the button color that the controls have. Then:
	- The controls with a window (CheckBox, OptionButton, Frame and others) are painted with the body behind them. This needs subclassing: with SubclassingMethod disabled or set to one of the "only UserControl" values they keep the button color.
	- The opaque Labels with that color are changed to a transparent BackStyle. This is done also at design time, and the change is saved in the form.


ChangeControlsForeColor property:
	Type: Boolean
	Returns or sets a value that determines whether the ForeColor of the contained controls is changed to the caption color of the selected tab. The default is True.
	
	Like with ChangeControlsBackColor, only the controls whose ForeColor is the color that the tab control gave them before are changed.
	The color they get is:
	- the ForeColorSelectedTab of the tab, or the one of the control when it was set by hand (or by a theme) and the selected tab has no highlight background. It is given as it is;
	- otherwise, the caption color, if it has enough contrast against the background of the selected tab. If it doesn't, the controls get black or white, whichever reads better. When the selected tab has a highlight background (HighlightModeSelectedTab), its caption color was chosen for that background and not for the body, so it is checked too.
	The ChangeControlForeColor event allows to exclude some controls.
	
	With the Windows visual styles, Windows draws the captions of CheckBox, OptionButton and Frame controls in the color of the theme, ignoring their ForeColor. With subclassing (see SubclassingMethod) the control draws them with their ForeColor: the VB ones, and the check boxes and option buttons that are Windows buttons, like the ones of VBCCR. Without subclassing they stay in the color of the theme, which can't be read over a dark body.


ClientHeight property:
	Type: Single (Read only)
	Returns the height of the client area, in twips. The client area is the inside of the body, where the contained controls go.
	It reaches the border line of the body, with no margin: the space between the controls and the border is up to your design.
	Reading it applies any pending change to the layout first.


ClientLeft property:
	Type: Single (Read only)
	Returns the left of the client area, in twips. The client area is the inside of the body, where the contained controls go.
	With RightToLeft set to True it is already mirrored: it can be used as it is to place a control.
	It reaches the border line of the body, with no margin. Reading it applies any pending change to the layout first.
	
	At some DPI settings that are not a multiple of 24 (like 175%), moving a control with these values can leave it a pixel or two off, because VB6 rounds the twips per pixel. FitToClientArea doesn't have that problem.


ClientTop property:
	Type: Single (Read only)
	Returns the top of the client area, in twips. The client area is the inside of the body, where the contained controls go.
	It reaches the border line of the body, with no margin. Reading it applies any pending change to the layout first.


ClientWidth property:
	Type: Single (Read only)
	Returns the width of the client area, in twips. The client area is the inside of the body, where the contained controls go.
	It reaches the border line of the body, with no margin. Reading it applies any pending change to the layout first.


CloseButton property:
	Type: Boolean
	Returns or sets a value that determines whether the tabs show a close button (an "x") that allows the user to close them.
	Each tab can override it with TabCloseButton. Where the buttons are shown is set by CloseButtonPosition.
	
	Clicking the button raises the CloseButtonClick event. If it is not canceled, the tab is hidden (TabVisible = False): it is not removed.
	In the TDI modes the mode decides which tabs have a close button, and this property and TabCloseButton are not used.


CloseButtonChar property:
	Type: Long
	Returns or sets the Unicode code of the character drawn as the close button, in the font of CloseButtonFont.
	0 (default) lets the control choose the character, according to the font that is used.


CloseButtonColor property:
	Type: Long
	Returns or sets the color of the close button of the inactive tabs, while the mouse is not over the button.
	While it is not set, it follows ForeColor.
	
	The close button has five colors: this one, CloseButtonColorSelectedTab for the selected tab, CloseButtonColorTabHighlighted for a tab under the mouse, and CloseButtonColorMouseHover and CloseButtonColorMouseHoverSelectedTab for the button itself under the mouse.


CloseButtonColorMouseHover property:
	Type: Long
	Returns or sets the color of the close button of an inactive tab while the mouse is over the button. The default is red.
	It is also used for the close button at the end of the tab strip (CloseButtonPosition = ntCBPositionStripEnd).


CloseButtonColorMouseHoverSelectedTab property:
	Type: Long
	Returns or sets the color of the close button of the selected tab while the mouse is over the button. The default is red, like CloseButtonColorMouseHover.


CloseButtonColorSelectedTab property:
	Type: Long
	Returns or sets the color of the close button of the selected tab, while the mouse is not over the button.
	While it is not set, it is inherited from CloseButtonColor or from ForeColorSelectedTab.


CloseButtonColorTabHighlighted property:
	Type: Long
	Returns or sets the color of the close button of an inactive tab while the mouse is over the tab but not over the button.
	While it is not set, it is inherited from CloseButtonColor or from ForeColorHighlighted.


CloseButtonFont property:
	Type: Font
	Returns or sets the font of the close button character.
	While it is not set, or if the font is not installed, the control uses the first one available of "Segoe MDL2 Assets", "Marlett" and "Arial". Setting it to Nothing goes back to that.
	The fonts are not part of the themes.


CloseButtonPadding property:
	Type: Long
	Returns or sets the space, in pixels, on each side of the close button of a tab: between the button and the caption, and between the button and the edge of the tab (there the larger of this value and TabPaddingWidth is used).
	The value is scaled by the DPI. It can be from 0 to 40; the default is 6.


CloseButtonPosition property:
	Type: NTCloseButtonPositionConstants
	Returns or sets where the close buttons are shown.
	
	Values:
	ntCBPositionOnTabs (default): on each tab that has one.
	ntCBPositionOnSelectedTab: only on the selected tab.
	ntCBPositionOnHoveredTab: only on the tab under the mouse.
	ntCBPositionOnSelectedAndHoveredTabs: on the selected tab and on the tab under the mouse.
	ntCBPositionStripEnd: a single button at the end of the tab strip, which closes the selected tab.
	
	With the values that show the button only on some tabs, every tab keeps the space of its button, so the tabs don't change their size when it appears.


Container property:
	Type: Object
	Returns or sets the container of the control.
	On a form, this is the property that VB adds to every control. The control also exposes it for code that uses it through a variable typed As NewTab.
	
	To put another control inside a NewTab by code, set that control's Container to the NewTab and then call ControlSetTab.


ControlLeft property:
	Type: Single
	
	Additional parameter(s):
	    In/Out	Required	nControl	As	Variant
	Returns or sets the Left of a contained control as if it were on the selected tab.
	
	The controls of the tabs that are not selected are moved LeftOffsetToHide twips to the left, so their real Left is not where they are shown. ControlLeft hides that: it returns and takes the position the control has when its tab is selected.
	The nControl parameter is the control, or its name as a String. For an element of a control array, the name includes the index, as in "Text1(2)".
	If the control is not found, error 1501 is raised.


Controls property:
	Type: ContainedControls (Read only)
	Returns the collection of the controls contained in the NewTab, of all the tabs.
	It holds only the controls placed directly on the NewTab, not the controls that are inside them (for example, inside a Frame).
	It is not available at design time.
	
	To get the controls of one tab, use TabControls.


DragIcon property:
	Type: Picture
	Returns or sets the icon used as the mouse pointer in a drag-and-drop operation.


DragMode property:
	Type: Integer
	Returns or sets a value that determines whether manual or automatic drag mode is used for a drag-and-drop operation.
	This is VB's drag and drop of the control itself. Dragging tabs to reorder them is set by CanReorderTabs.


Enabled property:
	Type: Boolean
	Returns or sets a value that determines whether the control responds to the user.
	A disabled control draws its captions and icons grayed. ShowDisabledState grays also the background of the tabs.
	To disable one tab, use TabEnabled.


EndOfTabs property:
	Type: Single (Read only)
	Returns the position where the last tab ends, along the tab strip, in units of the container.
	For the orientations with the tabs at the top or bottom, it is a horizontal position; for the others, a vertical one.


FlatBarColorHighlighted property:
	Type: Long
	Returns or sets the color of the bar of a tab under the mouse, in the Flat style.
	While it is not set, it is a tint of FlatBarColorSelectedTab: that color mixed at 60% with BackColorTabs.
	The bar is shown when HighlightMode has the ntHLFlatBar flag.


FlatBarColorInactive property:
	Type: Long
	Returns or sets the color of the bar of the inactive tabs, in the Flat style.
	The inactive tabs show a bar when HighlightMode has the ntHLFlatBar flag. Some themes hide it by giving it the background color of the tabs.


FlatBarColorSelectedTab property:
	Type: Long
	Returns or sets the color of the bar of the selected tab, in the Flat style.
	It is the accent color of the Flat style: FlatBarColorHighlighted and the border colors of the tabs follow it while they are not set.
	The bar is shown when HighlightModeSelectedTab has the ntHLFlatBar flag.


FlatBarGripHeight property:
	Type: Long
	Returns or sets the height, in pixels, of the grip of the bar in the Flat style: a small rise in the middle of the bar. A negative value makes a notch instead.
	The grip is drawn when the highlight mode has the ntHLFlatBarGrip flag along with ntHLFlatBar.
	The value is scaled by the DPI. It can be from -50 to 50; the default is -5.


FlatBarHeight property:
	Type: Long
	Returns or sets the height, in pixels, of the bar of the tabs in the Flat style.
	The value is scaled by the DPI. It can be from 0 to 15; the default is 3.


FlatBarPosition property:
	Type: NTFlatBarPositionConstants
	Returns or sets on which side of the tab the bar is drawn in the Flat style: ntBarPositionTop (default), on the outer side of the tab, or ntBarPositionBottom, on the side of the body.
	Top and bottom are as seen with the tabs at the top; in the other orientations the bar turns with the tabs.


FlatBodySeparationLineColor property:
	Type: Long
	Returns or sets the color of the line between the tabs and the body, in the Flat style.


FlatBodySeparationLineHeight property:
	Type: Long
	Returns or sets the height, in pixels, of the line between the tabs and the body, in the Flat style. 0 draws no line.
	The value is scaled by the DPI, except a height of 1, which stays one pixel at any DPI. It can be from 0 to 50; the default is 1.
	With a value other than 1 the top corners of the body are square. With 0, they are rounded only under a tab whose bottom is closed, so the side of the body doesn't end in the air.


FlatBorderColor property:
	Type: Long
	Returns or sets the color of the border in the Flat style.


FlatBorderMode property:
	Type: NTFlatBorderModeConstants
	Returns or sets what the border goes around in the Flat style.
	
	Values:
	ntBorderTabs (default): around the body and all the tabs.
	ntBorderSelectedTab: around the body and the selected tab only.
	
	With ntBorderSelectedTab, when the selected tab or the tab under the mouse is at an end of the front row and rounds its bottom together with the body, the stretch of border under its curve is left open, and what is behind shows there. That is intended.


FlatRoundnessBottom property:
	Type: Long
	Returns or sets the radius, in pixels, of the corners of the body on the side opposite to the tabs, in the Flat style. 0 makes them square.
	The value is scaled by the DPI. It can be from 0 to 100; the default is 8.
	With rounded corners, FitToClientArea clips the contained controls to them.


FlatRoundnessTabs property:
	Type: Long
	Returns or sets the radius, in pixels, of the corners of the tabs, in the Flat style. 0 (default) makes them square.
	The value is scaled by the DPI. It can be from 0 to 100.
	
	With several rows of tabs, without perspective and with this value at 0, the ends of the front rows are square and the ntHLRoundBottom highlight flag has no effect. To get rounded tabs in every row, use a value greater than 0, or ShowRowsInPerspective.


FlatRoundnessTop property:
	Type: Long
	Returns or sets the radius, in pixels, of the corners of the body on the side of the tabs, in the Flat style. 0 makes them square.
	The corners are rounded only where no tab covers them.
	The value is scaled by the DPI. It can be from 0 to 100; the default is 8.
	With rounded corners, FitToClientArea clips the contained controls to them.


FlatTabBodyGap property:
	Type: Long
	Returns or sets a space, in pixels, added to the tabs on the side of the body, in the Flat style.
	The tabs grow by that amount. With AutoTabHeight set to False, it is taken from the fixed TabHeight instead.
	The tabs that round their bottom with the highlight (the ntHLRoundBottom flag) leave the space empty, so they look floating over the body; the other tabs paint it.
	The value is scaled by the DPI. It can be from 0 to 50; the default is 0.


FlatTabBorderColorHighlighted property:
	Type: Long
	Returns or sets the color of the border of a tab under the mouse, in the Flat style, when HighlightMode has the ntHLFlatDrawBorder flag.
	While it is not set, it takes the color of the bar of that state, FlatBarColorHighlighted.


FlatTabBorderColorInactive property:
	Type: Long
	Returns or sets the color of the border of the inactive tabs, in the Flat style, when HighlightMode has the flags ntHLFlatShapeInactive and ntHLFlatDrawBorder.
	While it is not set, it takes the color of the bar of the inactive tabs, FlatBarColorInactive. Some themes hide that bar by giving it the background color; with them the border is not seen until it gets a color of its own.


FlatTabBorderColorSelectedTab property:
	Type: Long
	Returns or sets the color of the border of the selected tab, in the Flat style, when HighlightModeSelectedTab has the ntHLFlatDrawBorder flag.
	While it is not set, it takes the color of the bar of the selected tab, FlatBarColorSelectedTab.


FlatTabsSeparationLineColor property:
	Type: Long
	Returns or sets the color of the lines between the tabs, in the Flat style.


Font property:
	Type: Font
	Returns or sets the font of the captions of the tabs.
	With AutoTabHeight set to True, the height of the tabs follows the font.
	The font is not part of the themes: applying a theme doesn't change it.


ForeColor property:
	Type: Long
	Returns or sets the color of the captions of the inactive tabs.
	While it is not set, it follows the text color of the container.
	The other caption and icon colors (ForeColorSelectedTab, ForeColorHighlighted, IconColor and others) follow it while they are not set.


ForeColorHighlighted property:
	Type: Long
	Returns or sets the color of the caption of an inactive tab while the mouse is over it.
	While it is not set, it follows ForeColor.


ForeColorSelectedTab property:
	Type: Long
	Returns or sets the color of the caption of the selected tab.
	While it is not set, it follows ForeColor.
	If ChangeControlsForeColor is True, it is also the color given to the contained controls, unless it doesn't contrast with the body while the selected tab has a highlight background (see ChangeControlsForeColor).


HandleHighContrastTheme property:
	Type: Boolean
	Returns or sets a value that determines whether the control changes its colors automatically when Windows switches to a high contrast theme, and back. The default is True.
	With high contrast the control uses the system colors of that theme, and the contained controls are given those colors too (at run time).


Height property:
	Type: Single
	Returns or sets the height of the control.


HelpContextID property:
	Type: Long
	Returns or sets the context ID of a topic in a Help file, shown when the user presses F1 while the control has the focus.


HighlightColor property:
	Type: Long
	Returns or sets the color of the background highlight of an inactive tab while the mouse is over it.
	It is used when HighlightMode has a background flag (ntHLBackgroundPlain, ntHLBackgroundGradient or ntHLBackgroundDoubleGradient). The gradients go from this color to HighlightGradientColor.


HighlightColorSelectedTab property:
	Type: Long
	Returns or sets the color of the background highlight of the selected tab.
	It is used when HighlightModeSelectedTab has a background flag. The gradients go from this color to HighlightGradientColorSelectedTab.


HighlightEffect property:
	Type: NTAnimationSpeedConstants
	Returns or sets the speed at which the highlight of a tab appears when the mouse moves over it, or ntAnimationNone for it to appear at once. The default is ntAnimationFast.


HighlightEffectOut property:
	Type: NTAnimationSpeedConstants
	Returns or sets the speed at which the highlight of a tab fades away when the mouse leaves it, or ntAnimationNone for it to disappear at once. The default is ntAnimationMedium.


HighlightGradientColor property:
	Type: Long
	Returns or sets the second color of the gradients that highlight an inactive tab under the mouse (the first one is HighlightColor).
	While it is not set, it is the background color of the tab.
	It is only the second color of the gradient: it doesn't change the color of the tab or of the body.


HighlightGradientColorSelectedTab property:
	Type: Long
	Returns or sets the second color of the gradients that highlight the selected tab (the first one is HighlightColorSelectedTab).
	While it is not set, it is the background color of the selected tab, so the gradient ends in the color of the body.
	If it is set to a color different from BackColorSelectedTab, the tab ends its gradient in that color and the body continues in its own, so a step is seen where they meet. To avoid it, leave it not set.
	It doesn't change the color of the body or the color given to the contained controls.


HighlightMode property:
	Type: NTHighlightModeFlagsConstants
	Returns or sets how the inactive tabs are highlighted while the mouse is over them.
	The selected tab has its own setting, HighlightModeSelectedTab.
	
	The value is a combination of the flags of NTHighlightModeFlagsConstants:
	- The background, one of: ntHLBackgroundPlain (4), ntHLBackgroundGradient (2) or ntHLBackgroundDoubleGradient (3). ntHLBackgroundLight (8) makes it lighter.
	- The caption: ntHLCaptionBold (16), ntHLCaptionUnderlined (32).
	- The size and position: ntHLExtraHeight (256) makes the tab taller by HighlightTabExtraHeight, ntHLShiftCaption (1024) moves its contents by HighlightTabCaptionShift, ntHLWidenTab (2048) widens it on both sides.
	- Flat style only: ntHLFlatBar (64) shows the bar, ntHLFlatBarGrip (128) adds a grip to the bar, ntHLFlatDrawBorder (512) draws a border around the tab, ntHLRoundBottom (4096) rounds also the corners of the tab on the side of the body, ntHLFlatShapeInactive (8192) gives the inactive tabs, also when the mouse is not over them, the shape of the highlighted one (only for this property).
	ntHLNone (1) is no highlight, and ntHLAuto (0), the default, lets Style decide:
	- Flat: background gradient, light, and the bar.
	- Windows: plain background.
	- Tabbed dialog, property page and TabStrip: none, like the original controls.
	
	While the tabs are drawn with the Windows visual styles, any background flag shows the "hot" look of Windows, and the gradient and light flags make no difference. The caption, size and position flags work in every style.
	The Highlight page of the property pages disables the flags that have no effect with the current settings.


HighlightModeSelectedTab property:
	Type: NTHighlightModeFlagsConstants
	Returns or sets how the selected tab is highlighted. Unlike the inactive tabs, it is always highlighted, whether the mouse is over it or not.
	
	The value is a combination of the same flags as HighlightMode, except ntHLFlatShapeInactive.
	With ntHLAuto (default) it depends on Style:
	- Flat: background gradient, light, and the bar.
	- Tabbed dialog: bold caption, like SSTab.
	- Property page: extra height and widened tab.
	- TabStrip and Windows: extra height, widened tab and shifted caption, like the TabStrip control.
	A value set by hand replaces the Auto answer, it is not added to it.
	
	While the tabs are drawn with the Windows visual styles, the background of the selected tab is painted by Windows and the background flags have no effect.

	Type: Single
	Returns or sets the height added to a highlighted tab, in units of the container.
	It is applied only when the highlight mode has the ntHLExtraHeight flag. The tab grows towards the outside of the tab strip.

	Type: Long (Read only, not available at design time)

IconAlignment property:
	Type: NTIconAlignmentConstants
	Returns or sets where the icon or picture of each tab goes, with respect to the caption.
	
	Values:
	ntIconAlignCenteredBeforeCaption (default): before the caption. When the caption is aligned to a side, the icon is centered in the free space on its side if there is enough room, so it doesn't look stuck to the caption.
	ntIconAlignBeforeCaption: right before the caption, the two aligned together.
	ntIconAlignCenteredAfterCaption and ntIconAlignAfterCaption: the same, after the caption.
	ntIconAlignStart: at the start edge of the tab; the caption is aligned in the remaining space.
	ntIconAlignEnd: at the end edge of the tab.
	ntIconAlignCenteredOnTab: the icon in the middle of the tab, with the caption after it. If the tab has no room for that, it falls back to the pair centered.
	ntIconAlignAtTop and ntIconAlignAtBottom: above or below the caption.
	
	"Before" and "start" follow the reading order of the caption: with RightToLeft they are on the right, and in the Left and LeftTop orientations, whose captions read from bottom to top, they are below.
	With the caption centered (CaptionAlignment), the "Centered" values draw the same as the others.
	With the icon above or below the caption, the captions of all the tabs with an icon are at the same height, and the icons are centered in the height of the largest one. A tab without icon centers its caption.

TabMovable property:
	Type: Boolean

	    In	Required	nTab	As	Variant
	Returns or sets whether the user can move a tab by dragging it, when CanReorderTabs is True. The default is True.
	A tab that can't be moved also stays in its place when others are dragged around it. So the fixed tabs split the strip into zones: a tab can only be dragged inside the zone between the fixed tabs around it.
	It affects only the user: MoveTab can still move the tab.


TabOrientation property:
	Type: NTTabOrientationConstants
	Returns or sets on which side of the control the tabs are, and how they are aligned.
	
	Values:
	ssTabOrientationTop, ssTabOrientationBottom, ssTabOrientationLeft and ssTabOrientationRight: the four of SSTab. The captions of the side tabs are rotated.
	ntTabOrientationTopRight, ntTabOrientationBottomRight, ntTabOrientationLeftTop and ntTabOrientationRightBottom: the same sides, with the tabs aligned at the other end.
	ntTabOrientationLeftHorizontal, ntTabOrientationRightHorizontal, ntTabOrientationLeftBottomHorizontal and ntTabOrientationRightBottomHorizontal: the tabs on a side with horizontal captions. How the tabs share the length of the side is set by TabHeightStyleForHorizontal.
	
	The captions of the Left and LeftTop orientations read from bottom to top, and those of Right and RightBottom from top to bottom.
	With RightToLeft, left and right swap.
	
	Note: the value 10 used to be called ntTabOrientationLeftTopHorizontal, and now is ntTabOrientationLeftBottomHorizontal. Code that uses the old name doesn't compile; forms saved with earlier versions are converted when they are loaded.

Tabs property:
	Type: Long

TabsOverflow property:
	Type: NTTabsOverflowConstants
	Returns or sets what the tab strip does when the tabs don't fit in one row.
	
	Values:
	ntTOMultiRow (default): more rows of tabs are added, as SSTab does.
	ntTOScroll: there is always one row, and when it doesn't fit, two buttons at its ends scroll it. The mouse wheel over the strip scrolls it too.
	ntTOScrollWithList: the same, plus a button that shows the list of all the tabs in a menu, to go to any of them.
	
	The scroll and list buttons are shown only while the row doesn't fit. Holding a scroll button down repeats, like a key. The selected tab is always scrolled into view.
	With scrolling, TabsPerRow used with ntTWEqualWidth is the number of tabs seen at a time.


TabsPerRow property:
	Type: Long
	Returns or sets the number of tabs on each row. A value less than 1 raises error 380. The default is 3.
	It applies when TabWidthStyle is ntTWEqualWidth, ntTWTabCaptionWidth or ntTWGeneralFixedWidth (or ntTWAuto resolving to one of them). With the other settings the control decides how many tabs go on a row.
	With ntTWEqualWidth, all the tabs have the width of the control divided by TabsPerRow. With fixed widths that don't fit in the row, the last tab goes out of the control: TabsPerRow decides how many tabs go on a row and none moves to the next one.

TabVisible property:
	Type: Boolean
	
	Additional parameter(s):
	    In	Required	nTab	As	Variant
	Returns or sets whether a tab is visible.
	Hiding the selected tab selects a neighbor tab: the previous one, or the next one if there is none. If that change is canceled in the BeforeClick event, the tab is not hidden.
	At run time all the tabs can be hidden; then Tab is -1, and showing a tab again selects it.
	A hidden tab keeps its index and its controls. The close button hides the tab instead of removing it.


TabWidthStyle property:
	Type: NTTabWidthStyleConstants
	Returns or sets how the width of the tabs is decided.
	
	Values:
	ntTWAuto (default): it depends on Style, and on the TDI mode and the new tab button. See below.
	ntTWEqualWidth: all the tabs have the same width: the width of the control divided by TabsPerRow. In earlier versions this value was called ntTWFixed.
	ntTWTabCaptionWidth: each tab is as wide as its caption and icon need, within TabMinWidth and TabMaxWidth. A new row starts every TabsPerRow tabs. If a row doesn't fit, its tabs are made narrower.
	ntTWTabStripEmulation: like the TabStrip control: each tab as wide as its caption, and when they don't fit in one row, they are distributed evenly in several rows and stretched so that every row fills the width of the control. If they fit in one row, they are not stretched.
	ntTWStretchToFill: like ntTWTabStripEmulation, but a single row is also stretched to fill the width.
	ntTWTabCaptionWidthFillRows: each tab as wide as its caption; when they don't fit in one row a new row is started, without distributing them evenly, so one row can have eight tabs and the next one one. With several rows, each row is stretched to fill the width.
	ntTWGeneralFixedWidth: all the tabs have the width of TabGeneralFixedWidth, TabsPerRow per row.
	ntTWGeneralFixedWidthFillRows: all the tabs start with the width of TabGeneralFixedWidth, and the rows are filled as with ntTWTabCaptionWidthFillRows.
	
	ntTWAuto resolves to:
	- in a TDI mode, or with the new tab button: ntTWTabCaptionWidthFillRows;
	- tabbed dialog: ntTWEqualWidth, like SSTab;
	- property page: ntTWTabCaptionWidth, like SSTab;
	- TabStrip: ntTWTabStripEmulation;
	- Flat and Windows: ntTWStretchToFill.
	
	A tab with TabFixedWidth keeps its own width with any of them.
	In the side orientations with horizontal captions this property is not used: see TabHeightStyleForHorizontal.

TDIFormsIconSize property:
	Type: NTTDIFormsIconSizeConstants
	Returns or sets, in the TDI Forms mode, the size at which the icons of the forms are shown in the tabs. The size is given for 96 DPI and is scaled with the DPI, like TabPic16 and its companions. The default is ntTDIFormsIcon24.
	Form icons are 32 x 32, which is usually too large for a tab. ntTDIFormsIconNative shows them at their own size.
	The TDIFormsShowTabIcon event can change the size for one tab.


TDIMode property:
	Type: NTTDIModeConstants
	Returns or sets whether the control works as a TDI (Tabbed Document Interface) and in which mode. In a TDI mode the user opens and closes tabs, and the control handles them.
	
	Values:
	ntTDIModeNone (default): normal mode.
	ntTDIModeControls: each tab is a "document" made of the controls of tab 0, which is a template and is hidden at run time. Put the controls on tab 0 at design time, all of them as control arrays with Index 0. For each new tab the controls are loaded again (with Load) and placed on it. Your code tells the copies apart by their Index. A new tab button ("+") opens new tabs.
	ntTDIModeForms: the NewTab hosts the other forms of the program, like an MDI form but with tabs. Place it on the main form, sized to fill it; every form that is shown afterwards opens in a new tab, and closing the tab unloads it. Tab 0, called "Home", is always there and can't be closed: it can hold controls of the main form, like a menu of the program.
	
	It can only be changed on a control that was just placed on the form, with its initial tabs and no contained controls. At design time the property pages say why it can't be changed; at run time error 1391 is raised.
	At run time it can be set on a control created with Controls.Add, before the control is shown. For the Controls mode, set the mode, then put the template controls into tab 0 with Container and ControlSetTab; the mode starts when the control is shown.
	
	In the TDI modes:
	- AddTab and RemoveTab are not available, and Tabs can't be changed at design time.
	- The mode decides which tabs have a close button.
	- TDIBeforeNewTab, TDINewTabAdded, TDIBeforeClosingTab and TDITabClosed tell when tabs are opened and closed. Their TabNumber parameter identifies a tab for as long as it lives; nTab is its current index, which changes when the tabs are reordered.


TDINewTabCaption property:
	Type: String
	Returns or sets, in the TDI Controls mode, the caption of the tabs added with the new tab button. The default is "New tab".
	The TDIBeforeNewTab event can still change it for each tab.


Theme property:
	Type: String
	Returns or sets the theme of the control, by its name.
	
	A theme is a named set of property settings, mostly of appearance: colors, style, highlight, Flat settings and others. Setting Theme applies those settings once: they are written into the properties, saved with the form like any other setting, and can be changed afterwards. The control doesn't keep a link to the theme.
	Reading Theme returns the name of the theme that matches the current settings, or "Custom" if none matches. So after changing a property of a theme by hand, it returns "Custom".
	The names are not case sensitive. A name that doesn't exist raises error 380.
	
	The fonts, the texts and the colors of the strip buttons are not part of the themes.
	The Themes page of the property pages shows the themes with a preview, and allows to save custom themes to a file, to the registry, or to the form.

AddTab function:
	Return Type:	Long
	Parameter(s):
	    In	Optional	Caption	As	Variant
	    In	Optional	Key	As	String
	    In	Optional	ToolTipText	As	String
	    In	Optional	CloseButton	As	NTAutoYesNoConstants	Default value: ntYNAuto (2)
	    In	Optional	Index	As	Long	Default value: -1

	Adds a tab and returns the index where it was placed, or -1 if it could not be added.
	
	Parameters, all optional:
	Caption: the caption of the tab. If it is not given, the caption is "Tab" and the index. An empty string gives a tab without caption, for a tab that shows only an icon.
	Key: the TabKey of the tab. A key that is already used raises error 457.
	ToolTipText: the TabToolTipText of the tab.
	CloseButton: the TabCloseButton setting of the tab.
	Index: where to insert it, from 0 to Tabs. Without it, the tab is added after the last one. An invalid index raises error 5.
	
	Everything is checked before the tab is created, so when an error is raised no tab was added.
	The new tab is not selected. To select it: NewTab1.Tab = NewTab1.AddTab("Caption")
	It is not available in the TDI modes (error 1387).
	
	Tip: to find the tab later even if the user reorders the tabs, give it a Key.


ControlGetTab function:
	Return Type:	Long
	Parameter(s):
	    In/Out	Required	nControl	As	Variant

	Returns the index of the tab where a contained control is, or -1 if the control is not on the NewTab.
	The nControl parameter is the control, or its name as a String; for an element of a control array, with its index, as in "Text1(2)".


ControlMove method:
	Parameter(s):
	    In/Out	Required	nControl	As	Variant
	    In	Required	Left	As	Single
	    In	Required	Top	As	Single
	    In	Optional	Width	As	Variant
	    In	Optional	Height	As	Variant
	    In	Optional	TabToMoveTheControl	As	Variant

	Moves a contained control, like its Move method, but with the position it has when its tab is selected.
	The controls of the tabs that are not selected are moved to the left to hide them (LeftOffsetToHide), so calling Move on them directly would show them. ControlMove takes that into account.
	
	Parameters:
	nControl: the control, or its name as a String; for an element of a control array, with its index, as in "Text1(2)".
	Left, Top: the new position, in units of the container.
	Width, Height: optional, the new size.
	TabToMoveTheControl: optional, a tab to move the control to, by index, key or caption.


ControlSetTab method:
	Parameter(s):
	    In/Out	Required	nControl	As	Variant

	NewTab1.ControlSetTab Text1, 2

FindTab function:
	Return Type:	Long
	Parameter(s):
	    In	Required	Find	As	Variant
	    In	Optional	Method	As	NTFindTabMethodConstants	Default value: ntFindCaption (0)
	    In/Out	Optional	StartingTab	As	Variant

	Finds a tab and returns its index, or -1 if it is not found. It doesn't change the selected tab.
	
	Parameters:
	Find: what to look for.
	Method: optional, where to look for it. One of:
	ntFindCaption (default): the TabCaption.
	ntFindPartialCaption: a part of the caption.
	ntFindPartialCaptionReverse: a part of the caption, starting from the last tab.
	ntFindKey: the TabKey.
	ntFindTag: the TabTag.
	ntFindData: the TabData.
	ntFindOriginalIndex: the index the tab had when it was created. For the tabs added at run time, it is the order of creation.
	ntFindContainedControl: the tab that holds the control given in Find.
	StartingTab: optional, the index of the tab where the search starts.
	
	With CanReorderTabs, the user can change the indexes of the tabs: FindTab(2, ntFindOriginalIndex) finds the tab that was at position 2 at design time, wherever it is now.


FitToClientArea method:
	Parameter(s):
	    In	Required	nControl	As	Object
	    In	Optional	AutoRefit	As	Boolean	Default value: True

	Places a contained control so that it fills the client area (the inside of the body), and clips it to the rounded corners of the body if there are any.
	
	Parameters:
	nControl: the control. It must have a window (a hWnd) and be placed directly on the NewTab; otherwise error 380 is raised.
	AutoRefit: optional. With True (default), the control is fitted again every time the client area changes: when the NewTab is resized, the rows change, and so on. With False, it is fitted only once.
	
	It works in pixels, so unlike moving the control with ClientLeft and the others, it is exact at any DPI setting. It works with RightToLeft too.
	The control is not given any margin: if you want one, place the control inside a container (for example a PictureBox) and fit the container.
	ReleaseFromClientArea stops fitting it and removes the clipping.
	
	NewTab1.FitToClientArea Picture1
	


GetClientRgn function:
	Return Type:	LongPtr
	No parameters.

	Returns a new GDI region with the shape of the client area, or 0 if the body has no rounded corners.
	The region is in the coordinates of the client area: 0, 0 is its top left corner.
	The caller owns the region: pass it to the SetWindowRgn API, which keeps it, or delete it with DeleteObject. Since SetWindowRgn hWnd, 0, True removes any clipping, the result can be passed without checking it.
	FitToClientArea does all this by itself.

RemoveTab function:
	Return Type:	Boolean
	Parameter(s):
	    In	Required	nTab	As	Variant

	Removes a tab and returns True if it was removed. nTab is the tab, by index, key or caption.
	The tabs after it move one place back.
	
	Errors:
	- 5: the tab doesn't exist.

	Return Type:	Boolean

TDIFormsShowTabIcon event:
	Parameter(s):
	    Info	TabNumber	As	Long
	    Info	nTab	As	Long
	    Info	FormCaption	As	String
	    Info	FormhWnd	As	LongPtr
	    Returns value	IconPicture	As	Object
	    Returns value	IconLeftOffset	As	Long
	    Returns value	IconTopOffset	As	Long
	    Returns value	IconWidth	As	Long
	    Returns value	IconHeight	As	Long
	    Returns value	UseIconFont	As	Boolean
	    Returns value	IconFont	As	Object
	    Returns value	IconChar	As	Variant
	    Returns value	IconColor	As	Long
	    Returns value	IconColorHighlighted	As	Long
	    Returns value	IconColorSelected	As	Long
	    Returns value	IconInColor	As	Boolean
	    Returns value	NoIcon	As	Boolean
	In the TDI Forms mode, occurs when the icon of the tab of a form is going to be drawn, and allows to change it: the picture, its size and position, or an icon from a font instead.
	The icon is asked for when it is drawn, so the event can be raised many times for the same tab.
	
	Parameters:
	TabNumber: identifies the tab for as long as it lives. nTab: its current index, which changes when the tabs are reordered.
	FormCaption and FormhWnd: to identify the form.
	IconPicture: the picture to show, by default the icon of the form. It can be set to another icon or bitmap. It is declared As Object to avoid a dependency on the stdole2 type library.

	IconColor, IconColorHighlighted and IconColorSelected: the colors of the icon character for the normal, highlighted and selected states. When they are not changed, the tab uses the icon colors of the control.
	IconInColor: draws the icon character with the colors of the font (Windows 8.1 or later).
	NoIcon: set to True to show no icon.

*NewTabTheme object*
- A theme: a named set of property settings stored together, mostly about appearance. The available themes are in the NewTabThemes collection that the Themes property returns, and one is applied by setting its name in the Theme property.

Properties: 

Custom property:
	Type: Boolean (Read only)
	Returns True for a custom theme, saved by the developer, and False for a built-in one.


Name property:
	Type: String (Read only)
	Returns the name of the theme, the one used in the Theme property.


*NewTabThemes object*
- The collection of the available themes, as NewTabTheme objects: the built-in ones followed by the custom ones. It is returned by the Themes property, and can be walked with For Each.

Dim iTheme As NewTabTheme
For Each iTheme In NewTab1.Themes
    List1.AddItem iTheme.Name
Next


Properties: 

Count property:
	Type: Long (Read only)
	Returns the number of themes in the collection.


Item property:
	Type: NewTabTheme (Default property, read only)
	
	Additional parameter(s):
	    In	Required	IndexOrKey	As	Variant
	Returns a theme of the collection, by its position (starting at 1) or by its name. This is the default member. A theme that doesn't exist raises error 5.


Methods: 

Exists function:
	Return Type:	Boolean
	Parameter(s):
	    In	Required	nThemeName	As	String

	Returns True if there is a theme with that name in the collection. The names are not case sensitive.

	Parameter(s):
	    In	Required	nThemeName	As	String

	Removes a theme from this collection, by its name. A theme that doesn't exist raises error 5.

Rename method:
	Parameter(s):
	    In	Required	nOldThemeName	As	String
	    In	Required	nNewThemeName	As	String

	Renames a theme of this collection. Error 5 is raised if the theme doesn't exist or the new name is already used.
